# ✨ Character and Word Counter

## 📌 About the Project

The Character and Word Counter is a simple, interactive web application that counts characters, words, and sentences while the user types into a text area.

This project was created as part of my **Day 18 Web Development Challenge**.

## 🎯 Objectives

- Practice JavaScript input events.
- Understand string methods and regular expressions.
- Update webpage content dynamically.
- Handle whitespace and empty input.
- Build a responsive and attractive interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🌟 Features

- Live character count, including spaces.
- Live word count with extra spaces handled correctly.
- Sentence count based on `.`, `!`, and `?`.
- Clear Text button to reset the input.
- Colorful gradient design.
- Responsive layout for mobile and desktop.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Type into the text area to see the counters update.

This project helped me understand JavaScript event listeners, string trimming, word splitting, regular expressions, and live DOM updates.
